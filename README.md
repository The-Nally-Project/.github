## Repository purpose

This is the organisation's shared documentation repository. Product implementations should live in focused repositories with their own code, tests, release processes and component-specific documentation.

Specifications describe intended behaviour and constraints. They do not claim that a feature has been implemented, deployed, independently audited or proven secure.
