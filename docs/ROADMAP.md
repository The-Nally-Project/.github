# Initial Roadmap

**Status:** Directional roadmap; milestones are not promises or release dates.

## Stage 0 — Project foundation

- [x] Create the GitHub organisation.
- [x] Publish the organisation profile.
- [ ] Publish charter, governance, contribution, conduct, and security policies.
- [ ] Establish issue, proposal, and release conventions.

## Stage 1 — Core specifications

- [ ] Define user, agent, and device identity boundaries.
- [ ] Specify the authority and permission model.
- [ ] Specify memory records, provenance, retention, export, and deletion.
- [ ] Define the capability and integration interface.
- [ ] Document threat models and trust boundaries.

## Stage 2 — Minimal-model research

- [ ] Compare compact classifier and small generative approaches.
- [ ] Define narrow task boundaries and escalation behaviour.
- [ ] Establish dataset provenance and licensing rules.
- [ ] Build a reproducible evaluation harness.
- [ ] Benchmark accuracy, calibration, latency, memory, and energy before selecting a model size.

## Stage 3 — Software prototype

- [ ] Build a narrow, testable orchestration prototype.
- [ ] Separate planning, approval, execution, and audit.
- [ ] Implement inspectable user memory controls.
- [ ] Add failure handling and observability.
- [ ] Run security and usability reviews.

## Stage 4 — Interoperability

- [ ] Select initial integrations based on user value and documented APIs.
- [ ] Implement scoped, revocable permissions.
- [ ] Test local and cloud execution paths.
- [ ] Publish integration guidance and compatibility tests.

## Stage 5 — Expansion

- [ ] Improve portability and local-first options.
- [ ] Evaluate additional languages and accessibility needs.
- [ ] Explore broader device and environment integrations.
- [ ] Establish sustainable maintainer and release processes.

## Release discipline

A stage is complete only when its acceptance criteria, tests, documentation, and known limitations are published. Roadmap items may be reordered when evidence or security findings justify a change.
