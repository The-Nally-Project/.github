# The Nally Project

**Building personal intelligence for a connected world.**

The Nally Project is an open-source initiative to build a personal intelligence layer that works across devices, applications, and environments.

Our goal is to make useful intelligence accessible while keeping people in control of their personal memories, settings, and delegated authority.

## What we're building

- Personal intelligence across devices and services.
- An open, modular ecosystem with documented interfaces.
- User-controlled memory and transparent data practices.
- Hybrid intelligence combining local capabilities, Nally-developed models, and external models.
- Interoperability with existing platforms.

## Principles

1. User autonomy and informed consent.
2. Privacy and security by design.
3. Open-source development and transparent governance.
4. Least-privilege access and revocable permissions.
5. Evidence-led engineering and measurable reliability.
6. Accessibility across devices and connectivity conditions.
